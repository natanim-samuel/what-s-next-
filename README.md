# 📋 What's Next?

A web-based group project planning and task management application designed to help teams organize their work, track responsibilities, and stay on top of upcoming tasks.

## 📌 About the Project

What's Next? is a collaborative planning website created to help groups manage projects more effectively.

The application allows team members to organize their project plans, keep track of tasks, assign responsibilities, and see what needs to be done next.

The goal is to make group projects easier to coordinate by keeping tasks, responsibilities, and progress organized in one place.

## ✨ Features

### 📋 Project Planning

- Create and organize projects
- Plan upcoming work
- Break projects into individual tasks
- Track project progress

### ✅ Task Management

- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Track pending tasks
- Organize tasks by priority

### 👥 Group Collaboration

- Manage project members
- Assign tasks to team members
- See who is responsible for each task
- Track individual responsibilities

### 📅 Planning

- View upcoming tasks
- Organize work by deadlines
- Keep track of project schedules
- Identify what needs to be done next

### 📊 Progress Tracking

- Monitor completed tasks
- Track remaining work
- View overall project progress
- Organize tasks based on their status
